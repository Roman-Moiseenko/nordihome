
2.1. Поиск
Топ запросов — что ищут чаще всего.
Запросы без результатов — товара нет, упущенная выручка.
Запросы с низким CTR — находят, но не кликают.
Средняя позиция клика — насколько релевантна выдача.
Поисковые сессии без покупки — воронка «поиск → корзина».
История поиска клиента — для персональных рекомендаций.
2.2. Просмотры страниц
Топ товаров по просмотрам — какие товары привлекают.
Топ категорий — какие разделы популярнее.
Среднее время на странице — вовлечённость.
Глубина прокрутки — читают ли описание.
Страницы с высоким отказом — плохой контент, медленная загрузка.
Точки входа — через какие страницы приходят.
Точки выхода — где теряют клиента.
Путь клиента — последовательность страниц перед покупкой.
2.3. Действия клиента
Добавления в корзину — какие товары добавляют, но не покупают.
Удаления из корзины — почему отказываются (цена, доставка).
Изменения количества — какие объёмы заказывают.
Избранное — товары в листе ожидания.
Клики по кнопкам — «Купить в 1 клик», «Задать вопрос», «Позвонить».
Отправки форм — какими формами пользуются.
Поля форм с фокусом без отправки — где бросают.
Клики по баннерам и акциям — эффективность промо.
2.4. Источники и каналы
UTM-кампании — какая реклама приводит клиентов.
Источник входа — Google, Яндекс, VK, Telegram, прямой заход.
Конверсия по источникам — какой канал даёт покупки, а не просто трафик.
Стоимость привлечения (если есть данные о расходах).
Referrer — конкретные сайты-источники.
2.5. Аудитория
География — города, регионы.
Устройство — desktop / mobile / tablet.
ОС и браузер — под что оптимизировать.
Новые vs вернувшиеся — retention.
Частота визитов — как часто возвращаются.
Время между визитами — цикл покупки.

2.6. Воронка продаж
Путь клиента от входа до покупки — сколько шагов.
Отвал на каждом шаге — где теряется больше всего.
Время до первой покупки — как быстро решается.
Повторные покупки — retention.
Брошенные корзины — товар добавлен, но заказ не оформлен.
2.7. Персонализация
Что смотрел конкретный клиент — для рекомендаций.
Что искал — для персональных подборок.
Категории интереса — для email-рассылок.
Ценовой диапазон — для показа релевантных товаров.
Предпочтения по бренду — для рекомендаций.
2.8. Маркетинг и реклама
ROI по UTM-кампаниям — какие кампании окупаются.
Клики по промо-баннерам — эффективность.
Участие в акциях — сколько клиентов вовлечено.
Поведение клиентов из разных каналов — какие более активны.
Look-alike аудитории — на кого похожи покупатели.
2.9. Технические метрики
Скорость страниц (через performance.timing ).
Ошибки JS — какие баги ломают пользователям опыт.
Ошибки API — какие запросы падают.
Битые ссылки — 404-страницы.
Медленные запросы — где клиент ждёт.
2.10. SEO и контент
Популярные страницы блога — какой контент читают.
Переходы из блога в каталог — работает ли контент-маркетинг.
Время чтения статей — вовлечённость.
Глубина прокрутки в статьях — дочитывают ли.
Запросы с мобильных vs десктоп — как отличается поведение.
2.11. Продуктовые метрики
Товары-лидеры — по просмотрам, добавлениям, покупкам.
Товары-аутсайдеры — много просмотров, мало покупок.
Товары из поиска без покупки — проблема с ценой или описанием.
Кросс-продажи — что покупают вместе.
Возвраты к товару — сколько раз возвращаются перед покупкой.
